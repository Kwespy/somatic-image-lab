Donis A. Dondis
Dondis llama alfabetidad visual a la capacidad de reconocer cómo una imagen organiza sus elementos para comunicar algo, en vez de tomar su efecto como natural.
Dondis calls visual literacy the ability to recognise how an image organises its elements to communicate something, rather than taking its effect as natural.
elemento → contraste → organización → mensaje
element → contrast → organisation → message
en 1 minuto
in 1 minute

Para Dondis, ver no equivale automáticamente a leer. Una imagen puede parecer inmediata, pero su mensaje depende de decisiones: qué se separa, qué se repite, qué contrasta y qué queda subordinado.

La alfabetidad visual no es un código fijo como la gramática. Es una práctica para describir esas decisiones y comparar el mensaje construido con el que recibe quien mira.

El contraste organiza diferencia: puede hacer que algo sobresalga, acelerar una lectura o volver dominante una parte. Por eso una composición no es solo un soporte: es una manera de orientar atención.

For Dondis, seeing does not automatically mean reading. An image can seem immediate, but its message depends on decisions: what is separated, repeated, contrasted and subordinated.

Visual literacy is not a fixed code like grammar. It is a practice for describing these decisions and comparing the constructed message with what a viewer receives.

Contrast organises difference: it can make something stand out, speed up looking or make one part dominant. A composition is therefore a way of directing attention.

tres cosas para conservar
three things to keep
Una imagen enseña una jerarquía incluso cuando parece espontánea.
Contraste no significa solo color: también puede ser escala, posición, textura o repetición.
Leer visualmente es comparar lo que se muestra con la organización que lo hace visible.
An image teaches a hierarchy even when it appears spontaneous.
Contrast is not only colour: it can be scale, position, texture or repetition.
Visual reading compares what is shown with the organisation that makes it visible.
punto de arrastre
carry point
El reading 030 preguntó qué sostiene una imagen para que su atención parezca estable. Dondis permite precisar esa pregunta: ¿qué decisiones visuales enseñan esa estabilidad como si fuera natural?
Reading 030 asked what holds an image in place so that attention seems stable. Dondis makes the question more precise: which visual decisions teach that stability as if it were natural?
por ejemplo
for example

Abre una publicación de noticias en el teléfono: una foto, un titular grande, una etiqueta roja y tres enlaces pequeños. Antes de leer, la etiqueta y el titular ya han decidido qué parece urgente.

Guarda una captura y comprueba fuente, fecha, encuadre y el orden de los módulos. Luego tapa con la mano la etiqueta roja y mira de nuevo. Repite ocultando el titular. No cambió el archivo, pero sí la jerarquía que la interfaz construye.

La prueba no dice que el contraste mienta. Pregunta qué lectura vuelve probable cuando una plataforma hace que una pieza sea más grande, más roja o aparezca antes que las demás.

Open a news post on a phone: a photograph, a large headline, a red label and three small links. Before reading, the label and headline have already decided what appears urgent.

Save a screenshot and check source, date, framing and module order. Then cover the red label with your hand and look again. Repeat with the headline. The file did not change, but the hierarchy built by the interface did.

The test does not say contrast lies. It asks what reading becomes likely when a platform makes one piece larger, redder or earlier than the rest.

residue
Hacer visible una jerarquía no la desactiva. Pero permite decidir si queremos seguirla, invertirla o volverla discutible.
Making a hierarchy visible does not deactivate it. But it lets us decide whether to follow, reverse or contest it.

Una imagen solo se entiende cuando deja suficiente margen a la izquierda.
An image is only understood when it leaves enough margin on the left.
«Sangría» viene de la tipografía: nombra el desplazamiento que marca una relación entre líneas. Es una intervención de TSIL, no un concepto de Dondis. Al chocar con la sintaxis visual, pregunta qué desplazamientos mínimos hacen que algo parezca principal, secundario o fuera de lugar.
“Indent” comes from typography: it names a displacement that marks a relation between lines. It is a TSIL intervention, not Dondis’s concept. Colliding with visual syntax, it asks which minimal shifts make something appear primary, secondary or out of place.
